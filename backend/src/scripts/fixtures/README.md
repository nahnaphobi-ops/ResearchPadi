# Review dry-run fixtures

`review-sample-paper.md` and `review-sample-sources.json` are **fictional test data**
for `npm run review:dry-run`. The authors, journals and findings are made up. They are
not real works and must not be cited.

The sample paper has deliberate faults, so a working review should flag some of them:

- a subject-verb error in the abstract ("The results was significant")
- an overclaim with no support ("improves exam results for every student in every college")
- a citation that is not in the source list (Kwarteng, 2018) and an absolute claim ("always lowers attention")
- a repeated sentence in Chapter 1
